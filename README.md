# Hackathon0-Interstellar-Timekeeping

Prereqs:

As this Program is *unneccisarily* complex you will need the Dotnet-sdk, preferable version 10.

to run this program, go to its main directory "Hackathon0-Interstellar-Timekeeping/" and run `dotnet run -- "any recognised Exoplanet"` <-- For Example. `dotnet run -- "trappist-1 b` or `dotnet run -- "proxima centuari b` for a full list of recognised Exoplanets please reference [Nasa's Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/cgi-bin/TblView/nph-tblView?app=ExoTbls&config=PS)
